This site tracks **neural-network verification (NNV)** papers across 25 top conferences in artificial intelligence, machine learning, computer vision, programming languages, software engineering, formal methods, computer security, and robotics, grouped the same way as [CSRankings](https://csrankings.org/).

Only papers focused on NNV are counted, including verifiers, bound propagation, certified training, probabilistic certification, and verified control. See [Areas](areas/) for the full breakdown.
