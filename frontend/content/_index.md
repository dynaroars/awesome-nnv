This site tracks **neural-network verification (NNV)** papers across 16 top conferences in machine learning, computer vision, programming languages, software engineering, and formal methods, grouped the same way as [CSRankings](https://csrankings.org/).

Only papers focused on NNV are counted, including verifiers, bound propagation, certified training, probabilistic certification, and verified control. See [Areas](areas/) for the full breakdown.
