November 2017

AAAI 2018 decisions: safe reinforcement learning through formal verification with verified runtime monitoring and through shielding, alongside verification of properties of binarized deep neural networks.

3 NNV papers accepted in November 2017, at AAAI 2018.

  • AAAI 2018 NN control systems Safe Reinforcement Learning via Formal Methods: Toward Safe Control Through Proof and Learning
    Nathan Fulton, André Platzer

    Ensures safe reinforcement learning by combining formal verification with verified runtime monitoring: safety guarantees hold while the agent explores within verified control choices, and on model violations it learns to return to modelled states; demonstrated on adaptive cruise control.

  • AAAI 2018 NN control systems Safe Reinforcement Learning via Shielding (arXiv)
    Mohammed Alshiekh, Roderick Bloem, Rüdiger Ehlers, Bettina Könighofer, Scott Niekum, Ufuk Topcu

    Learns optimal reinforcement learning policies while enforcing temporal logic safety specifications with a synthesized shield that either restricts the agent to safe actions before it decides or corrects unsafe actions after, gives conditions to preserve learning convergence, and demonstrates it on several challenging scenarios.

  • AAAI 2018 Quantized & bit-levelComplete verification Verifying Properties of Binarized Deep Neural Networks (arXiv)
    Nina Narodytska, Shiva Prasad Kasiviswanathan, Leonid Ryzhyk, Mooly Sagiv, Toby Walsh

    Verifies properties of binarized neural networks, especially adversarial robustness, by encoding them exactly as Boolean formulas and using modern SAT solvers with a counterexample-guided search, scaling to medium-size image classification networks.
