March 2019

CVPR 2019 decisions: verification of output-size specifications for machine translation and image captioning models, and robustness verification of classification networks with sigmoid activations via linear programming.

2 NNV papers accepted in March 2019, at CVPR 2019.

  • CVPR 2019 Beyond linear output propertiesBeyond feed-forward nets Knowing When to Stop: Evaluation and Verification of Conformity to Output-Size Specifications
    Chenglong Wang, Rudy Bunel, Krishnamurthy Dvijotham, Po-Sen Huang, Edward Grefenstette, Pushmeet Kohli

    Studies attacks that lengthen outputs of variable-length models, using a differentiable proxy to find inputs giving outputs 50 times longer, and a verification method that proves output length stays below a bound for machine translation and image captioning models.

  • CVPR 2019 Bound propagation & abstract interpretation Robustness Verification of Classification Deep Neural Networks via Linear Programming
    Wang Lin, Zhengfeng Yang, Xin Chen, Qingye Zhao, Xiangkun Li, Zhiming Liu, Jifeng He

    Verifies robustness of classification networks with sigmoid activations by recasting it as checking the most suspected input point, a nonlinear optimization relaxed into a linear program; experiments show better precision and scalability on image classifiers.
