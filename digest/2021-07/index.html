July 2021

ASE 2021, CCS 2021 and ICCV 2021 decisions: semantic transformations are a common theme, with TSS and 3DCertify for point clouds, alongside Cert-RNN for recurrent networks, DetectorGuard for object detectors and integer-only certification for quantized neural networks. ASE added DFV, which uses distribution models for falsification and verification.

7 NNV papers accepted in July 2021, at ASE 2021, CCS 2021 and ICCV 2021.

CCS 2021 4 papers

  • CCS 2021 Beyond feed-forward netsBound propagation & abstract interpretation Cert-RNN: Towards Certifying the Robustness of Recurrent Neural Networks
    Tianyu Du, Shouling Ji, Lujia Shen, Yao Zhang, Jinfeng Li, Jie Shi, Chengfang Fang, Jianwei Yin, Raheem Beyah, Ting Wang

    Cert-RNN certifies robustness of recurrent networks such as vanilla RNNs and LSTMs with precise abstract transformers for their nonlinear operations, giving bounds on average 1.86 times larger than POPQORN on an MNIST sequence model.

  • CCS 2021 OtherBeyond ℓp input propertiesBeyond linear output properties DetectorGuard: Provably Securing Object Detectors against Localized Patch Hiding Attacks
    Chong Xiang, Prateek Mittal

    DetectorGuard provably secures object detectors against localized patch hiding attacks by checking objectness from a robust image classifier against detector boxes, so a certified object is detected or an alert is raised, at under 1% clean cost.

  • CCS 2021 Certified trainingGlobal & relational properties Learning Security Classifiers with Verified Global Robustness Properties
    Yizheng Chen, Shiqi Wang, Yue Qin, Xiaojing Liao, Suman Jana, David A. Wagner

    Trains security classifiers, structured as ensembles of logic rules, to satisfy verified global robustness properties via a booster-fixer scheme using counterexample guided inductive synthesis; a Twitter spam classifier meets five properties with a 5.4% drop in true positive rate.

  • CCS 2021 Beyond ℓp input propertiesProbabilistic certification TSS: Transformation-Specific Smoothing for Robustness Certification
    Linyi Li, Maurice Weber, Xiaojun Xu, Luka Rimanic, Bhavya Kailkhura, Tao Xie, Ce Zhang, Bo Li

    TSS certifies robustness against semantic transformations, using transformation-specific randomized smoothing for resolvable ones like blur and stratified sampling for interpolating ones like rotation; it reaches 30.4% certified accuracy against rotations within 30 degrees on ImageNet.

ICCV 2021 2 papers

  • ICCV 2021 Probabilistic certificationQuantized & bit-level Integer-arithmetic-only Certified Robustness for Quantized Neural Networks
    Haowen Lin, Jian Lou, Li Xiong, Cyrus Shahabi

    An integer randomized smoothing method with quantization gives smoothed classifiers that use only integer arithmetic, with a tight l2 robustness guarantee, matching accuracy and running 4 to 5 times faster than floating-point certified methods on CPUs and mobile devices.

  • ICCV 2021 Beyond ℓp input propertiesBeyond feed-forward netsBound propagation & abstract interpretation Robustness Certification for Point Cloud Models
    Tobias Lorenz, Anian Ruoss, Mislav Balunovic, Gagandeep Singh, Martin Vechev

    3DCertify verifies robustness of 3D point cloud models to semantic transformations using first-order Taylor relaxations for any differentiable transformation and a precise max-pool relaxation; it certifies 95.7% of point clouds against rotations of 60 degrees.

ASE 2021 1 paper

  • ASE 2021 Other Distribution Models for Falsification and Verification of DNNs
    Felipe Toledo, David Shriver, Sebastian Elbaum, Matthew B. Dwyer

    DFV learns an input distribution model, prefixes it to the DNN and restates the property over its input space so existing falsifiers and verifiers target realistic inputs; a study with 7 tools and 93 models shows more representative counterexamples.
